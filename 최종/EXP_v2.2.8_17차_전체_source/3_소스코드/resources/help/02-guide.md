# 상품 편집

## 상품 추가와 수정
상품 관리에서 추가를 누르거나 수정할 상품을 선택해 편집창을 여세요.
왼쪽에는 상품명, 가격, 수량, 카테고리, 상품 상태와 태그를 입력합니다. 카테고리는 대분류부터 차례대로 선택하세요.
## 설명과 사진
오른쪽에는 상품 설명을 적고 사진을 추가하세요. 설명의 줄바꿈은 저장 후에도 유지됩니다. 태그는 쉼표 또는 띄어쓰기로 구분합니다.
상품 저장을 누르면 목록에 반영됩니다. 취소를 누르면 입력한 변경 사항을 적용하지 않습니다.
## 등록 전 확인
가격과 사진 순서, 카테고리를 확인하세요. 등록한 상품의 제목과 상세 내용은 번개장터에 게시되는 정보이므로 저장 전에 다시 읽어 주세요.

## 배송 설정
편집창 아래의 배송 설정에서 배송비 포함 여부를 선택하세요. 포함을 선택하면 별도 배송 요금은 입력하지 않습니다.
배송비 별도 상품은 일반택배 요금을 100~30,000원으로 입력하세요. 기존에 저장한 별도 배송 상품도 요금을 한 번 입력해야 합니다.
반값택배는 불가능 또는 가능을 선택합니다. 가능하면 둘 다 가능, GS25 만, CU만 중 하나를 고르고 반값택배 요금을 입력하세요. 실제 등록 시 번개장터가 제시하는 요금 범위와 상품 조건을 확인하며, 적용할 수 없는 값이면 등록 전에 중단합니다.
다음 등록시에도 사용을 선택하면 번개장터의 같은 옵션을 켭니다. EXP에 저장한 상품별 배송 설정은 매번 등록할 때 적용합니다.
