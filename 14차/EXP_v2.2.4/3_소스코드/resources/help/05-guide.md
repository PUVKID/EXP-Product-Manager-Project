# 자동 등록

## 등록 시작
상품을 준비하고 예약에서 등록 방식과 간격을 설정하세요. 자동 등록의 시작을 누르면 대상 상품을 순서대로 처리합니다.
현재 상품, 진행 수, 다음 실행 시각을 화면에서 확인할 수 있습니다. 일시정지는 진행을 잠시 멈추며 다시 누르면 이어서 실행합니다. 중지는 이번 작업을 종료합니다.
## 실패한 상품
상품 관리의 상태를 확인하고 상품 정보와 사진을 수정하세요. 자동 등록이 중단되면 화면의 안내를 먼저 확인한 뒤 다시 시작합니다.
## 사용량 차감
등록 버튼 제출 직전에 1회 차감됩니다. 제출 후 결과가 불확실해도 차감은 유지됩니다. 이미 게시되었는지 내 상점에서 확인한 뒤 재시도하세요.
