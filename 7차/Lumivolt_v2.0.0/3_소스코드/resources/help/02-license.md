# 라이선스 등록

라이선스 키는 **이 PC 한 대**에서만 사용할 수 있고, 기재된 기간 동안만 유효합니다.

## 등록 순서
1. 인증 창(또는 왼쪽 메뉴의 **라이선스**)에서 **PC 고유번호**를 확인합니다. 형식은 `XXXX-XXXX-XXXX` 입니다.
2. **복사** 버튼으로 복사해 관리자에게 보냅니다.
3. 관리자에게 받은 **라이선스 키**를 키 입력 칸에 붙여 넣고 **인증**을 누릅니다.
4. "인증되었습니다"가 나오면 완료입니다. 다음 실행부터는 다시 묻지 않습니다.

## 라이선스 화면에서 볼 수 있는 것
- 라이선스 이름, 만료일, 남은 기간
- PC 고유번호와 복사 버튼

> 라이선스 키는 다른 PC에서 사용할 수 없습니다. PC를 바꾸거나 윈도우를 새로 설치하면 새 키를 발급받아야 합니다.

> 시스템 날짜를 과거로 바꾸면 라이선스가 무효 처리됩니다.
