# Chrome 문제 해결

## 크롬이 열리자마자 닫힘
- 작업 관리자에서 `chrome.exe` 를 모두 종료한 뒤 다시 시도하세요. 이전에 남은 크롬이 같은 프로필을 잡고 있을 때 생깁니다.
- 프로그램이 자동으로 호환 옵션, 새 임시 프로필 순으로 세 번까지 다시 시도합니다. 새 임시 프로필로 열린 경우 그 실행에서는 로그인이 유지되지 않습니다.

## 크롬을 찾지 못함
- Google Chrome 이 설치되어 있어야 합니다. 설치 후 다시 실행하세요.

## ChromeDriver 문제
- 프로그램이 설치된 크롬 버전에 맞는 ChromeDriver 를 확인하고 필요하면 내려받습니다. 처음 실행할 때 인터넷 연결이 필요합니다.
- 크롬이 자동 업데이트된 뒤 오류가 나면 프로그램을 다시 시작해 보세요.

## 윈도우 사용자 이름이 한글일 때
크롬 데이터 폴더를 자동으로 영문 경로(`C:\ProgramData\BunjangAuto` 또는 `C:\BunjangAuto`)로 옮겨 사용합니다. 정상 동작입니다.
