# 프로그램 시작하기

Lumivolt(루미볼트)는 번개장터에 올릴 상품 목록을 만들어 두면, 크롬 창을 자동으로 조작해 한 개씩 등록해 주는 프로그램입니다.

## 처음 실행하면
1. **이용약관**이 나타납니다. 내용을 읽고 동의해야 다음 단계로 넘어갑니다.
2. **라이선스 인증** 창에서 이 PC의 고유번호를 관리자에게 전달하고, 받은 키를 붙여 넣습니다.
3. 메인 화면이 열립니다. 왼쪽 메뉴로 화면을 옮겨 다닙니다.

## 왼쪽 메뉴
- **Dashboard** — 등록 대기·성공·실패 개수, 로그인·라이선스 상태, 최근 활동
- **상품 관리** — 상품 추가·편집·삭제, CSV 불러오기/저장
- **자동 등록** — 시작 / 일시정지 / 중지, 진행률
- **로그인** — 번개장터 로그인 확인
- **예약** — 1개씩 등록 간격, 시간대별 등록, 반복
- **로그** — 프로그램이 한 일의 기록
- **사용 설명서** — 지금 보고 있는 화면
- **설정**, **라이선스**

## 알아 두면 좋은 점
- 아이디와 비밀번호는 입력하지도, 저장하지도 않습니다. 크롬 창에서 직접 로그인합니다.
- 상품 목록과 설정은 이 PC에서만 열리도록 암호화되어 저장됩니다.
- 한 번에 하나의 프로그램만 실행됩니다. 이미 실행 중이면 "이미 실행 중입니다" 안내가 나옵니다.
