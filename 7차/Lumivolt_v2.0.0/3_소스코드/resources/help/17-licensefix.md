# 라이선스 문제 해결

| 안내 문구 | 원인과 해결 |
|---|---|
| 라이선스 키 형식이 올바르지 않습니다 | 키를 끝까지 복사했는지 확인. 앞뒤 공백·줄바꿈은 자동으로 지워집니다 |
| 라이선스 키가 올바르지 않습니다 | 잘못 복사했거나 위조된 키입니다 |
| 이 PC용 라이선스가 아닙니다 | 다른 PC의 고유번호로 발급된 키입니다. 이 PC의 고유번호를 다시 전달하세요 |
| 라이선스 기간이 만료되었습니다 | 관리자에게 연장 키를 요청하세요 |
| 시스템 날짜가 올바르지 않습니다 | PC 날짜와 시간을 바르게 고치세요 |
| 시스템 날짜가 과거로 바뀌었습니다 | 날짜를 되돌리면 라이선스가 무효가 됩니다. 날짜를 바로잡고 다시 실행하세요 |

## 분석 도구가 감지되었다는 안내
디버거나 분석 프로그램(dnSpy, x64dbg, Cheat Engine 등)이 실행 중이면 프로그램이 종료됩니다. 해당 프로그램을 닫고 다시 실행하세요.
