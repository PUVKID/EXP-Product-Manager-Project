# 이미지 등록

- 상품 하나에 사진은 **최대 12장**입니다.
- 형식은 jpg, jpeg, png, webp, gif 를 선택할 수 있습니다.
- **사진 지정**으로 고르거나, 상품 입력 창의 **사진 추가**를 사용합니다. 선택한 사진은 프로그램 데이터 폴더로 복사되므로 원본을 지워도 등록됩니다.
- 입력 창에서 **위로 / 아래로**로 순서를 바꿉니다. 맨 위 사진이 대표 사진입니다.
- CSV에서는 사진 경로를 세미콜론(;)으로 이어 적습니다. **상대 경로**를 쓰면 CSV 파일이 있는 폴더를 기준으로 찾습니다.

> 사진 파일이 없거나 경로가 틀리면 그 상품의 등록이 실패하고 로그에 이미지 업로드 실패가 남습니다.
