# 오류 해결

| 증상 | 먼저 해 볼 것 |
|---|---|
| 등록이 "실패: ..."로 끝남 | 로그의 실패 이유를 읽고, 카테고리 철자·사진 경로·가격을 확인 |
| 입력칸에 값이 정확히 안 들어갔다는 경고 | 크롬 창을 건드리지 말고 다시 시도 |
| 번개장터 화면이 바뀐 것 같음 | `selectors.json` 이 새 화면을 못 찾는 경우입니다. 관리자에게 로그와 캡처를 보내세요 |
| 작업 중 갑자기 멈춤 | 로그 마지막 줄 확인, 크롬 창이 닫혔는지 확인 |
| 상품 목록이 비어 있음 | 로그에 "상품 목록 파일을 열 수 없습니다"가 있는지 확인. 다른 PC에서 옮긴 파일은 열리지 않으므로 CSV 백업을 불러오세요 |

## 상품 목록 백업
상품 목록은 PC에 암호화되어 저장되어서, PC를 바꾸거나 윈도우를 새로 설치하면 복구할 수 없습니다. 평소에 **CSV 저장**으로 백업해 두세요.
