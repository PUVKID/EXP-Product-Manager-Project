# 반복과 시간대 예약

## 등록 방식 선택
예약의 등록 방식에서 **한 번**, **1개씩**, **전체 목록 반복** 중 하나를 고르세요. 선택한 방식에 필요한 입력만 표시됩니다. 시작한 뒤에는 예약 설정을 바꿀 수 없습니다. 중지 후 변경하세요.

## 전체 목록 반복
Studio / Pro에서 사용할 수 있습니다. 기본 설정에서는 유효한 전체 상품 목록을 즉시 등록한 뒤 반복합니다. 이미 등록된 상품도 포함하며, 한 회차의 전체 목록은 순서대로 처리합니다.

- **N분 간격**: 1~1440분. 15:02에 시작하고 60분으로 설정하면 다음 시각은 16:02입니다.
- **매시 지정분**: 0~59분. 15:02에 시작하고 0분을 선택하면 다음 시각은 16:00, 20분을 선택하면 15:20입니다.

오래 걸린 회차 뒤에는 다음 미래 시각을 기다리며, 지나간 회차를 몰아 실행하지 않습니다. 자동 등록 화면에서 현재 방식과 다음 실행 시각을 확인할 수 있습니다. 대기 중에도 일시정지·계속·중지를 사용할 수 있습니다.

로그인 실패, 예외, 시도한 상품이 없는 회차는 중단합니다. 개별 상품 실패가 있으면 나머지 상품까지 처리한 뒤 안내하고 반복을 중단합니다. 기존 인증과 일일 등록 한도가 적용됩니다.

## 매일 실행 시간 제한
전체 목록 반복에서만 사용할 수 있으며 기본은 꺼짐입니다. 켜면 시작·종료 시각이 펼쳐집니다. 기본 입력은 **18:00 ~ 24:00**이며 한국 시각을 사용합니다. 시작 시각은 포함하고 종료 시각은 제외합니다. **24:00은 종료에서만 허용하며 그날 자정**을 뜻합니다. 22:00 ~ 02:00처럼 다음 날 종료하는 범위도 설정할 수 있습니다. 시작과 종료를 같게 입력하면 실행할 수 없습니다.

시간 제한을 켜고 매시 00분으로 설정하면 17:30에 시작을 눌러도 18:00까지 기다립니다. 18:02에 시작하면 19:00에 시작하고, 18:00 정각이면 즉시 시작합니다. 18:00 ~ 24:00에서는 18~23시에 실행하며 다음 날 18:00까지 기다립니다. N분 간격도 이 제한을 따르며 시작 버튼을 누른 시각을 기준으로 간격을 유지합니다. 간격의 모든 실행 시각이 허용 범위 밖이면 안내 후 시작을 중단하므로 간격이나 시간 범위를 변경하세요.

**시작할 때 1회 즉시 등록**을 켜면 시간대 밖에서도 최초 전체 목록 1회는 즉시 실행합니다. 예를 들어 17:30에 시작하면 그때 전체 목록을 1회 등록하고 18:00부터 매시 지정분에 반복합니다. 이후 회차는 실행 시간 제한을 따릅니다. 이 옵션도 기본은 꺼짐이며 인증·상품 검증·등록 한도를 면제하지 않습니다.

종료 시각 이후에는 새 상품을 시작하지 않고 이미 처리 중인 상품만 마무리합니다. 일시정지나 서버 시각 미확인 상태에서 돌아오면 다음 슬롯을 다시 계산합니다. 타이머가 예정된 분 안에 늦게 호출되면 실행하지만 그 분을 넘기면 지나간 회차를 건너뜁니다. 시간 제한을 끄면 기존 첫 회차 즉시 실행 방식을 유지합니다. 실행 중에는 이 설정도 바꿀 수 없으며 저장한 값은 다음 실행에서 복원됩니다.

## 1개씩 등록
상품 사이의 기본 간격을 분 단위로 입력하세요. 시간대별 간격을 켜면 시간표가 펼쳐집니다. 시간대는 한국 시각 기준이며, 겹치면 나중에 시작한 시간대가 우선합니다. 목록 완료 후 반복을 켜면 처음 1회를 포함한 총 횟수를 지정할 수 있습니다. 시간대·반복·이미 등록된 상품 포함은 Studio / Pro에서 사용할 수 있습니다.

## 다음 예약 시작
번개장터 서버 시각이 확인되어야 시작할 수 있습니다. 실행 중 설정은 시작할 때의 값으로 유지됩니다.

시간대 입력은 09:00 형식이며 자정을 넘는 시간대도 사용할 수 있습니다. 예를 들어 08:50 등록 후 간격이 45분이어도 새 시간대가 09:00에 시작하면 09:00부터 다음 상품을 처리하며 이전 대기시간을 이어 가지 않습니다.
