# 설정

## 화면 테마
라이트, 다크 또는 시스템을 선택하세요. 시스템은 Windows의 앱 모드에 따라 바뀝니다. 선택한 테마는 다음 실행에도 유지됩니다.
## Chrome
일반적으로 Chrome 위치는 자동으로 찾습니다. Chrome을 실행할 수 없을 때 찾아보기를 눌러 설치된 chrome.exe를 지정하세요. 입력칸을 비우면 자동 탐색을 사용합니다.
## 자가진단
진단 시작을 눌러 인증과 실행 환경을 확인하세요. FAIL 항목을 먼저 해결한 뒤 다시 시도합니다. 설정을 변경해도 저장된 상품과 라이선스의 사용 기간은 유지됩니다.
