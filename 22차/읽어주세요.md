# EXP 22차 · 2.4.1

## 18:00~24:00에만 정각 등록하기

1. 예약에서 ‘전체 목록 반복’을 선택합니다.
2. ‘매시 지정분’을 선택하고 00분으로 맞춥니다.
3. ‘매일 실행 시간 제한’을 켭니다.
4. 시작 18:00, 종료 24:00을 선택합니다.
5. 자동 등록 화면에서 시작합니다.

18:00·19:00·20:00·21:00·22:00·23:00에 전체 유효 목록을 등록합니다. 24:00에는 새 회차나 새 상품을 시작하지 않고 다음 날 18:00까지 기다립니다. 이미 처리 중인 상품은 마무리합니다. 서버 한국 시각을 기준으로 합니다.

## 시작할 때 한 번 바로 등록하기

‘시작할 때 1회 즉시 등록’을 켜면 17:30에 시작해도 전체 목록을 바로 한 번 등록하고, 이후 18:00부터 정각마다 반복합니다. 첫 1회에 한해 실행 시간대 밖 등록을 허용합니다. 그다음부터는 설정한 시간대가 적용됩니다.

옵션을 끄면 17:30 시작은 18:00까지, 18:02 시작은 19:00까지 기다립니다. 회차가 오래 걸려 예정 시각을 넘기면 겹쳐 실행하지 않고 다음 미래 슬롯을 기다립니다.

## 시간 설정

- 시작·종료 입력에 시각을 직접 입력하거나 옆의 조절 버튼을 사용할 수 있습니다.
- N분 간격에도 같은 시간 제한을 적용할 수 있습니다.
- 22:00~02:00처럼 자정을 넘는 시간대도 지원합니다.
- 시작과 종료는 다르게 선택합니다. 24:00은 종료에서만 사용할 수 있습니다.
- 시간 제한을 끄면 기존 방식대로 첫 회차를 즉시 시작합니다.
- 실행 중 시간 설정을 바꾸려면 중지한 뒤 수정합니다.

전체 목록 반복은 Studio·Pro에서 사용하며 기존 일일 등록 한도가 적용됩니다. 앱과 PC가 켜져 있어야 합니다. 중지·한도·인증·상품 실패로 중단되면 문제를 확인한 뒤 직접 다시 시작하세요.
