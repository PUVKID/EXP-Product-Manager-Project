# EXP 22차 검증 범위

버전 2.4.1. 매일 실행 시간대와 시작할 때 1회 즉시 등록 옵션을 추가했습니다.

구현자 Batch 검사 171개, 시간 설정 UI 검사 4,168개가 통과했습니다. 보안 원본 24개 해시와 UTF-8 소스 103개 검사를 통과했습니다. 사용자·관리자·초기화 EXE 및 Inno 설치 파일을 빌드하고 고객 ZIP과 SHA256SUMS를 생성했습니다.

새 시간 조건 검사는 서버 한국 시각의 18:00/24:00 경계, 시간대 밖 대기, 자정 이후 예약, 즉시 등록 옵션, 실행 중 설정 동결, 일시정지·시계 복귀, 종료 후 새 상품 차단을 포함합니다. 실제 운영 인증이나 게시 없이 격리 테스트로 확인했습니다. UI는 라이트·다크와 테스트 배율/작은 폭에서 렌더했습니다. 물리적으로 다른 PC에서 설치한 결과는 아닙니다.

독립 최종 결과는 evidence 폴더와 .codex/routing-state의 영수증을 참고하세요. 기존 20차와21차, 사용자 상품·인증 자료는 보존했습니다. 설치·실상품 게시·초기화는 대신 실행하지 않았습니다.
