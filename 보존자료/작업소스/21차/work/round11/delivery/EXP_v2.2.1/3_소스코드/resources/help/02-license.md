# 라이선스 등록

1. 설치 파일을 실행하고 인증 화면에서 **등록코드 복사**를 누르세요.
2. 복사한 내용을 판매자에게 보내 주세요.
3. 받은 인증키를 붙여 넣고 **인증하고 시작**을 누르세요. 키에 맞는 Classic / Studio / Pro가 설치됩니다.

## Pro 3시간 체험
첫 인증 화면에서 **체험판 요청 복사**를 누르면 요청 문구와 등록코드가 함께 복사됩니다.
expmasterxx00@gmail.com로 보내면 관리자가 발급 이력을 확인합니다. 받은 체험 키를 같은 화면에 붙여 넣으세요.
발급 시점부터 3시간이며, 같은 PC나 신청 이메일로 체험판을 다시 받을 수 없습니다. 재설치해도 시간이 다시 시작되지 않습니다.

## 연장 및 변경
앱의 라이선스 화면에서 새 인증키를 붙여 넣고 **인증**을 누르세요. 기존 상품과 설정은 유지됩니다.
기간제와 무기한 모두 지원합니다. 라이선스는 등록한 PC와 Windows 계정에 귀속됩니다.

## 추가 등록권
Pro의 라이선스 화면에서 받은 추가 등록권 키를 입력하고 **충전**을 누르세요. 기본 일일 한도를 모두 쓴 뒤에 추가 등록권을 사용합니다. 남은 추가 등록권은 다음 날에도 유지됩니다.
