# Pro 체험판

## 체험판 신청
첫 인증 화면의 체험판 요청 복사를 누르고 요청 내용을 expmasterxx00@gmail.com으로 보내 주세요. 이메일 제목은 체험판 기능 사용하기로 작성하면 됩니다.
받은 체험 키를 같은 인증 화면에 입력하세요. 정식 버전과 동일한 설치 파일을 사용합니다.
## 사용 시간과 제한
Pro 체험 시간은 첫 실행이 아닌 키 발급 시점부터 3시간입니다. 같은 키를 다시 입력해도 시간이 늘어나지 않습니다.
같은 기기 또는 신청 이메일에는 체험 키를 다시 발급하지 않습니다. 체험 기간이 끝나면 정식 키를 받아 라이선스 화면에서 인증하세요.
