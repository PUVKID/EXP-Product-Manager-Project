누락 차수 소스·도움말·빌드 및 설치 입력 공개 보완

1~22차와 최종 보관본을 비교해 공개 가능한 누락 자료를 보완한다.
22차 2.4.1, 21차의 중간 버전 2.2.5 보관 소스 및 과거 차수의 빌드·설치 입력을 추가한다.
도움말·라이선스·manifest·체크리스트·배포 도구를 포함한 원본 입력 599개를 복제하고 차수별 감사 근거를 기록한다.
최종 ZIP은 17차, 10차 ZIP 공개 소스는 9차와 바이트 동일함을 확인했다.
연락처 비식별화를 유지하고 개인키·발급 이력·상품·운영 데이터·바이너리는 제외한다.

검증: 스테이지 공백, 원본 해시·허용 변환·민감정보·전수 텍스트 누락·문서 제약 대조.
최초 독립 검증에서 발견한 누락은 수리했고 실패 기록을 보존한다.
제품 게시·인증·설치는 실행하지 않았다.
