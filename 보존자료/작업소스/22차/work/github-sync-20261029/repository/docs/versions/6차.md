## 🚀 실행 경로와 제약

Program.cs → MainForm.cs가 앱 진입 경로입니다. 선택한 차수의 프로젝트 설정·build.bat와 lib 참조를 먼저 확인하세요. 공개본에는 DLL·아이콘·글꼴·브랜드 이미지 등 일부 바이너리 빌드 입력이 빠져 있습니다. 각 차수의 빌드 스크립트와 리소스 구성을 확인하세요.

11차에는 2.2.2와 이전 2.2.1이 있으며, 12차에는 같은 2.2.2 묶음이 있습니다.

더 자세한 준비 조건·시험 범위·주의점은 [README](../../README.md#quick-start)와 [공개 사본의 처리 범위](../SANITIZATION.md)를 함께 확인해 주세요.
