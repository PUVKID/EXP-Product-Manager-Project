## ✨ 구현과 변경 내용

FluentControl의 공통 보간 타이머·VisibilityWatch, 카드 tint·hover 애니메이션이 들어갑니다. 팔레트와 선택 행·높이 변경은 화면 표현의 변화입니다.

근거: [FluentControl (1~341행)](../../18%EC%B0%A8/%EC%86%8C%EC%8A%A4%EC%BD%94%EB%93%9C/src/UI/Controls.cs#L1-L341) · [Theme (1~505행)](../../18%EC%B0%A8/%EC%86%8C%EC%8A%A4%EC%BD%94%EB%93%9C/src/Theme.cs#L1-L505)

아이콘 생성 도구는 코랄 세 줄 표식을 그립니다. 도구 파일·소스코드의 포장 변경을 등록 기능 전체 교체로 보지 않습니다.

근거: [make_brand_icon (1~15행)](../../18%EC%B0%A8/tools/make_brand_icon.py#L1-L15)

## 🚀 실행 경로와 제약

Program.cs → MainForm.cs가 앱 진입 경로입니다. 선택한 차수의 프로젝트 설정·build.bat와 lib 참조를 먼저 확인하세요. 공개본에는 DLL·아이콘·글꼴·브랜드 이미지 등 일부 바이너리 빌드 입력이 빠져 있습니다. 각 차수의 빌드 스크립트와 리소스 구성을 확인하세요.

11차에는 2.2.2와 이전 2.2.1이 있으며, 12차에는 같은 2.2.2 묶음이 있습니다.

더 자세한 준비 조건·시험 범위·주의점은 [README](../../README.md#quick-start)와 [공개 사본의 처리 범위](../SANITIZATION.md)를 함께 확인해 주세요.
