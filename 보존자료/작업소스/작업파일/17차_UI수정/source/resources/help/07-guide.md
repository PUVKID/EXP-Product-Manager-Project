# 제품 등급과 일일 한도

## 등급별 기능
- Classic: 하루 25개, 기본 등록과 간격 등록.
- Studio: 하루 50개, 반복 등록과 시간대 예약.
- Pro: 하루 100개, 반복 등록과 시간대 예약, 추가 등록권 충전.
## 한도 초기화
기본 한도는 한국시간 자정마다 초기화됩니다. 쓰지 않은 기본 한도는 다음 날에 누적되지 않습니다. 같은 기기에서 계정을 바꿔도 EXP의 하루 사용량은 합산됩니다. 번개장터 계정별 등록 제한은 번개장터에서 적용합니다.
## Pro 추가 등록권
구매 문의는 expmasterxx00@gmail.com으로 보내 주세요. 받은 키를 라이선스의 Pro 추가 등록권에 입력하고 충전을 누릅니다. 기본 100회를 먼저 사용하며 남은 추가 등록권은 이월됩니다. 추가 등록권은 EXP의 등록 한도를 늘리며 번개장터 자체 제한을 변경하지 않습니다.
