# 시작하기

## 처음 사용하는 순서
1. 설치 파일을 열고 등록코드를 판매자에게 보내세요.
2. 받은 인증키를 입력하면 키에 해당하는 Classic, Studio 또는 Pro가 설치됩니다.
3. 로그인에서 번개장터 계정으로 로그인하세요.
4. 상품 관리에서 상품과 사진을 추가한 뒤 자동 등록에서 시작을 누르세요.
## 다시 실행할 때
인증과 상품은 저장됩니다. 로그인 상태가 풀렸다면 로그인 화면에서 다시 확인하세요. 실행 중에는 PC를 켜 두고 절전 모드를 해제해 주세요.
