## 🎯 개발 내용

자동 로그인·끌올·삭제 후 재등록이 남은 초기 실행 흐름을 정리했습니다.

## ✨ 구현과 변경 내용

Bot.EnsureLogin은 제공한 ID·비밀번호 자동 입력을 시도합니다. BumpAll·DeleteProduct·Repost는 끌올·삭제·재등록 경로이므로 후대의 등록 전용 흐름과 구분합니다.

근거: [Bot (1~916행)](../../3%EC%B0%A8/3_%EC%86%8C%EC%8A%A4%EC%BD%94%EB%93%9C/src/Bot.cs#L1-L916)

Storage는 계정 암호를 Windows DPAPI로 보호하지만 설정·상품 JSON 전체는 평문으로 저장합니다. CSV는 기본 쉼표·정확한 머리글을 전제로 처리합니다.

근거: [Storage (1~230행)](../../3%EC%B0%A8/3_%EC%86%8C%EC%8A%A4%EC%BD%94%EB%93%9C/src/Storage.cs#L1-L230)

## 🚀 실행 경로와 제약

Program.cs → MainForm.cs가 앱 진입 경로입니다. 선택한 차수의 프로젝트 설정·build.bat와 lib 참조를 먼저 확인하세요. 현재 공개본에는 DLL·아이콘·글꼴·도움말·브랜드 이미지 등 빌드 입력이 빠져 있으며, 최신 build.bat의 위임 대상 build/Build.ps1도 포함되어 있지 않습니다. 

11차에는 2.2.2와 이전 2.2.1이 있으며, 12차에는 같은 2.2.2 묶음이 있습니다.

더 자세한 준비 조건·시험 범위·주의점은 [README](../../README.md#quick-start)와 [공개 사본의 처리 범위](../SANITIZATION.md)를 함께 확인해 주세요.
