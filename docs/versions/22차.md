# 22차 · 2.4.1 · 전체 목록 반복의 일일 시간대

[프로젝트](../../README.md) · [공개 소스](../../22차/소스코드/) · [20차 대비 파일 전체 차이](../revision-audit/22차.md)

원본 안내와 `BatchRepeatSchedule`, `Models`, `Runner`, `AutomationController`, `SchedulePage`를 대조했습니다. 매일 실행 시간 제한·자정을 넘는 시간대·24:00 종료와 시작할 때 한 번 즉시 등록하는 옵션을 포함합니다. 20차 현행 계열과 비교합니다. 21차 폴더는 이전 중간 버전 보관이므로 최신 제품 계열의 직전 버전으로 보지 않습니다.

- 18:00~24:00·매시 00분이면 18~23시에 회차를 시작합니다. 종료 경계에는 새 회차·상품을 시작하지 않고 처리 중 상품은 마무리합니다.
- 시작 1회 즉시 등록을 켜면 첫 회차만 시간대 밖에서도 시작할 수 있습니다. 이후에는 일일 시간대를 적용합니다.
- 옵션을 끄면 다음 허용 슬롯을 기다립니다. 완료 뒤 이미 지난 슬롯을 겹쳐 실행하지 않습니다. 간격 반복에서도 시작 기준 위상을 유지하며 허용 슬롯을 계산합니다.
- 시간 범위는 시작 00:00~23:59·종료 00:00~24:00이며 시작과 종료가 같은 값은 거부합니다. 22:00~02:00처럼 자정 통과를 지원합니다.
- `SoftTime`의 시각 입력과 예약 화면·도움말·반복 검사 파일을 포함합니다. 시간 설정을 바꾸려면 중지 후 수정해야 합니다.

전체 목록 반복은 Studio·Pro와 기존 일일 한도·서버 한국 시각 조건을 따릅니다. 앱과 PC가 켜져 있어야 하며 한도·인증·실패·중지 뒤 자동 정상 복구를 보장하지 않습니다.

공개 입력에는 의존 DLL·브랜드 그림·폰트 등의 빌드 자원이 빠져 있어 바로 빌드 가능한 배포판이 아닙니다. 이번 보관 검토에서는 상품 등록·설치·운영 프로세스 중지·라이선스 초기화를 실행하지 않았습니다. 원본과 공개 사본 일부의 CRLF/LF·BOM 차이는 기능 변경과 구분했습니다.
