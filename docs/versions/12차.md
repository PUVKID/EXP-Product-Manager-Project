# 12차 · 2.2.2 현재 묶음을 따로 보관한 차수

[프로젝트 소개](../../README.md) · [전체 차수 비교](../VERSIONS.md) · [원본 보관 폴더](../../12%EC%B0%A8/)

**자료 상태: 이전 보관본**

## 🎯 이 자료의 목적

이 문서는 2.2.2 현재 묶음을 따로 보관한 차수에 관한 안내입니다. 아래 설명은 보관된 소스의 동작과 차이를 정리했으며 새 실행 결과를 뜻하지 않습니다.

## ✨ 구현과 변경 내용

EXP_v2.2.2의 앱·관리자·공통 코드를 보관합니다. 11차의 이전버전_2.2.1 하위 묶음이 없다는 사실을 앱 기능 전체 삭제로 해석하지 않습니다.

근거: [AssemblyVersion (1~6행)](../../12%EC%B0%A8/EXP_v2.2.2/3_%EC%86%8C%EC%8A%A4%EC%BD%94%EB%93%9C/admin/AssemblyInfo.cs#L1-L6) · [Program (1~107행)](../../12%EC%B0%A8/EXP_v2.2.2/3_%EC%86%8C%EC%8A%A4%EC%BD%94%EB%93%9C/src/Program.cs#L1-L107)

11차의 같은 EXP_v2.2.2 상대 경로와 SHA를 대조해 읽을 수 있는 차수입니다. 파일 수가 줄었다는 이유만으로 기능 축소나 새 제품 버전을 주장하지 않습니다.

근거: [MainForm (1~260행)](../../12%EC%B0%A8/EXP_v2.2.2/3_%EC%86%8C%EC%8A%A4%EC%BD%94%EB%93%9C/src/MainForm.cs#L1-L260)

## 🔄 입력·처리·출력

| 단계 | 내용 |
| :--- | :--- |
| 입력 | 상품 목록·사진 경로·선택자·예약 설정 |
| 처리 | WinForms 편집 → Runner → Bot의 브라우저 작업 → 저장 콜백 |
| 출력 | 상품 상태·등록 ID·시각·운영 기록 |

## 🔎 이전 보관본과 비교

앞서 안내한 숫자 차수의 활성 소스와 정규화한 상대 경로·SHA-256 기준으로 코드·빌드 입력의 내용 차이가 없습니다. 보관 범위와 포장 구조는 다를 수 있습니다.

## 🚀 실행 경로와 제약

Program.cs → MainForm.cs가 앱 진입 경로입니다. 선택한 차수의 프로젝트 설정·build.bat와 lib 참조를 먼저 확인하세요. 현재 공개본에는 DLL·아이콘·글꼴·도움말·브랜드 이미지 등 빌드 입력이 빠져 있으며, 최신 build.bat의 위임 대상 build/Build.ps1도 포함되어 있지 않습니다. 전체 앱 빌드·외부 상품 등록·실제 라이선스 발급은 이번 문서 작업에서 실행하지 않았습니다.

현재 공개 목록에는 1차·10차 자료가 없습니다. 해당 차수의 코드·변경 내용을 추정해 만들지 않았습니다. 11차는 현재 2.2.2와 이전 2.2.1을 함께 보관하고, 12차는 같은 2.2.2 묶음을 따로 보관합니다.

더 자세한 준비 조건·시험 범위·주의점은 [README](../../README.md#quick-start)와 [공개 사본의 처리 범위](../SANITIZATION.md)를 함께 확인해 주세요.
