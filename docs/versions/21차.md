# 21차 · 중간 버전 2.2.5 보관과 이전 부분 소스

[프로젝트](../../README.md) · [차수 폴더](../../21차/) · [2.2.4 대비 전체 비교](../revision-audit/21차.md)

21차는 새 배포 완성본이 아닙니다. `보관자료/EXP_v2.2.5`에 이전 중간 2.2.5 소스를 보존하며 14차 2.2.4를 기준으로 사용량 저장 중단 복구·관련 검사·빌드 연결·버전 정보의 차이를 확인할 수 있습니다. 숫자 21차를 20차 이후 추가된 기능 버전으로 해석하지 않습니다.

별도 `제품소스/3_소스코드`는 AssemblyInfo의 2.1.0으로 식별되는 이전 Lumivolt 코드 10개 파일의 부분 보관입니다. 2.2.5 전체 소스와 혼합하지 않습니다. 차수 전체 파일 목록은 차수 보관 범위에서 확인합니다.

의존 DLL·바이너리 자산이 빠져 있어 이 사본만의 빌드 성공은 확인하지 않았습니다. 정적 내용·공개 파일의 비교 결과이며 새 앱 실행·등록 시험 결과가 아닙니다.
