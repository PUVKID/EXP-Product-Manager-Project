## ✨ 구현과 변경 내용

Bot는 계정 ID 조회 없이 기기 총량을 차감하고 등록 화면 진입 뒤·제출 직전에 로그인 상태를 다시 검사합니다.

근거: [Bot (1~834행)](../../16%EC%B0%A8/EXP_v2.2.7/3_%EC%86%8C%EC%8A%A4%EC%BD%94%EB%93%9C/src/Bot.cs#L1-L834) · [UsageQuota (1~142행)](../../16%EC%B0%A8/EXP_v2.2.7/3_%EC%86%8C%EC%8A%A4%EC%BD%94%EB%93%9C/src/Security/UsageQuota.cs#L1-L142)

Design은 SoftInput·자체 스크롤·SoftNumber·SoftDatePicker·AppDialog로 입력과 대화상자를 구성합니다.

근거: [Design (1~278행)](../../16%EC%B0%A8/EXP_v2.2.7/3_%EC%86%8C%EC%8A%A4%EC%BD%94%EB%93%9C/src/Design.cs#L1-L278)

## 🚀 실행 경로와 제약

Program.cs → MainForm.cs가 앱 진입 경로입니다. 선택한 차수의 프로젝트 설정·build.bat와 lib 참조를 먼저 확인하세요. 현재 공개본에는 DLL·아이콘·글꼴·도움말·브랜드 이미지 등 빌드 입력이 빠져 있으며, 최신 build.bat의 위임 대상 build/Build.ps1도 포함되어 있지 않습니다. 

11차에는 2.2.2와 이전 2.2.1이 있으며, 12차에는 같은 2.2.2 묶음이 있습니다.

더 자세한 준비 조건·시험 범위·주의점은 [README](../../README.md#quick-start)와 [공개 사본의 처리 범위](../SANITIZATION.md)를 함께 확인해 주세요.
