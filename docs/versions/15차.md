## ✨ 구현과 변경 내용

UsageQuota는 currentData·repair를 추적하고 다음 seq 발급 전에 PersistCopies로 중단된 저장을 마무리합니다. 연속 파일 교체 실패를 seq 불연속으로 오인하는 경로를 보완합니다.

근거: [UsageQuota (1~144행)](../../15%EC%B0%A8/EXP_v2.2.6/3_%EC%86%8C%EC%8A%A4%EC%BD%94%EB%93%9C/src/Security/UsageQuota.cs#L1-L144)

Bot의 Chrome 시작 실패 안내는 자가진단·Brand.Email을 연결합니다. 계정별 일일 차감은 아직 남아 있어 16차의 기기 총량 전용 방식과 다릅니다.

근거: [Bot (1~840행)](../../15%EC%B0%A8/EXP_v2.2.6/3_%EC%86%8C%EC%8A%A4%EC%BD%94%EB%93%9C/src/Bot.cs#L1-L840)

## 🚀 실행 경로와 제약

Program.cs → MainForm.cs가 앱 진입 경로입니다. 선택한 차수의 프로젝트 설정·build.bat와 lib 참조를 먼저 확인하세요. 현재 공개본에는 DLL·아이콘·글꼴·도움말·브랜드 이미지 등 빌드 입력이 빠져 있으며, 최신 build.bat의 위임 대상 build/Build.ps1도 포함되어 있지 않습니다. 

11차에는 2.2.2와 이전 2.2.1이 있으며, 12차에는 같은 2.2.2 묶음이 있습니다.

더 자세한 준비 조건·시험 범위·주의점은 [README](../../README.md#quick-start)와 [공개 사본의 처리 범위](../SANITIZATION.md)를 함께 확인해 주세요.
