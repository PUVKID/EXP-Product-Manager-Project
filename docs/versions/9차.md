## ✨ 구현과 변경 내용

UsageQuota는 계정별 일일 50회와 기기 등급별 총량을 함께 검사합니다. AutomationController는 서버 시각 유효성과 사용량 준비를 확인한 뒤 실행합니다.

근거: [UsageQuota (1~133행)](../../9%EC%B0%A8/EXP_v2.2.0/3_%EC%86%8C%EC%8A%A4%EC%BD%94%EB%93%9C/src/Security/UsageQuota.cs#L1-L133) · [AutomationController (1~262행)](../../9%EC%B0%A8/EXP_v2.2.0/3_%EC%86%8C%EC%8A%A4%EC%BD%94%EB%93%9C/src/UI/AutomationController.cs#L1-L262)

TelemetryService는 설정이 Active일 때 중앙 전송을 시작합니다. 공개 BuildConfig의 URL·등록 키는 비어 있어 기본 원문만으로 전송이 활성화되지 않습니다.

근거: [TelemetryService (1~98행)](../../9%EC%B0%A8/EXP_v2.2.0/3_%EC%86%8C%EC%8A%A4%EC%BD%94%EB%93%9C/src/Telemetry/TelemetryService.cs#L1-L98) · [BuildConfig (1~9행)](../../9%EC%B0%A8/EXP_v2.2.0/3_%EC%86%8C%EC%8A%A4%EC%BD%94%EB%93%9C/src/Telemetry/BuildConfig.cs#L1-L9)

화면에는 등급·체험판·잔여 시간과 도움말의 DocView 기반 렌더링이 연결됩니다. 관리자 발급·추가 등록권·체험판 도구도 별도로 나뉩니다.

근거: [DashboardPage (1~144행)](../../9%EC%B0%A8/EXP_v2.2.0/3_%EC%86%8C%EC%8A%A4%EC%BD%94%EB%93%9C/src/UI/Pages/DashboardPage.cs#L1-L144) · [HelpPage (1~90행)](../../9%EC%B0%A8/EXP_v2.2.0/3_%EC%86%8C%EC%8A%A4%EC%BD%94%EB%93%9C/src/UI/Pages/HelpPage.cs#L1-L90) · [TrialIssuer (1~28행)](../../9%EC%B0%A8/EXP_v2.2.0/3_%EC%86%8C%EC%8A%A4%EC%BD%94%EB%93%9C/admin/TrialIssuer.cs#L1-L28)

## 🚀 실행 경로와 제약

Program.cs → MainForm.cs가 앱 진입 경로입니다. 선택한 차수의 프로젝트 설정·build.bat와 lib 참조를 먼저 확인하세요. 공개본에는 DLL·아이콘·글꼴·브랜드 이미지 등 일부 바이너리 빌드 입력이 빠져 있습니다. 각 차수의 빌드 스크립트와 리소스 구성을 확인하세요.

11차에는 2.2.2와 이전 2.2.1이 있으며, 12차에는 같은 2.2.2 묶음이 있습니다.

더 자세한 준비 조건·시험 범위·주의점은 [README](../../README.md#quick-start)와 [공개 사본의 처리 범위](../SANITIZATION.md)를 함께 확인해 주세요.
