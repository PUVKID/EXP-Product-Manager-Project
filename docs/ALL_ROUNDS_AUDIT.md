실행 파일·DLL·압축물·개인키·발급 이력·운영 데이터와 공개 권한이 불명확한 바이너리 자산은 제외했습니다. 따라서 공개 사본은 단독 빌드에 필요한 모든 입력을 포함하지 않습니다. [공개 처리](SANITIZATION.md) · [차수 목록](VERSIONS.md)

독립 검증에서 빠진 텍스트 후보 293개를 확인해 도움말 220개, 라이선스 39개, 앱 manifest 15개, 시험 체크리스트 15개와 기타 입력 4개를 추가했습니다. 22차 검증·패키지 도구 3개도 보존했습니다. 추가 확인에서 발견된 개인키 XML 7개는 제외했습니다. 공개 도구의 기준 해시는 원본 기준이며 이 공개 사본이 그대로 통과한다는 뜻은 아닙니다.

`최종`에는 17차 2.2.8 전체 배포 ZIP과 고객 배포 ZIP이 있습니다. 전체 ZIP의 소스 트리 125개 파일은 17차 대응 파일과 모두 바이트 일치했고, 고객 ZIP의 5개 파일도 17차 대응 파일과 바이트 일치했습니다. ZIP은 공개하지 않았습니다. 10차 전체 ZIP의 공개 가능한 소스 텍스트 117개도 9차 대응 파일과 바이트 일치했으며, 10차 고객 ZIP에는 소스가 없습니다.
