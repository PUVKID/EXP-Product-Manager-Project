# 공개한 합성 시험 입력

## 검열 회귀시험 15개

`SelfTestV2.cs`의 고정 JWT·PEM 표식은 모두 `Redactor.Scrub`의 문자열 제거 결과를 검사하는 `Check` 입력입니다. 15개 파일에서 같은 두 고정 입력을 사용합니다. JWT는 HS256 서명 부분이 31바이트로 정규 32바이트와 다르고, PEM 본문은 12바이트의 시험 표식입니다. 실제 계정이나 개인키 자료로 사용되는 코드가 아닙니다. 원본 코드와 파일 SHA-256을 보존했습니다.

## 로컬 서버 시험 7개

`hardening_checks.py`, `test_server.py`, `regression.sh`의 고정 시험 계정은 임시 디렉터리·시험 데이터베이스를 만들고 루프백 서버에 접속하는 회귀시험에만 사용합니다. 테스트 사용자 생성·비밀번호 해시·인증 실패·권한·속도 제한을 검사하는 문맥을 확인했습니다. 외부 서비스 주소나 운영 계정 자료로 사용되는 리터럴이 아니며 원형을 보존했습니다.

## 검사 한계

파일 해시, UTF-8, 비밀정보의 종류별 문맥, Python 문법을 확인했습니다. C#은 연락처 변환 파일의 독립 컴파일 및 설정값이 있을 때/없을 때의 분리된 검사를 수행합니다. GUI·외부 등록·실제 라이선스 발급·전체 서버 회귀시험은 실행하지 않았습니다. 실제 개인키 XML과 실행 파일은 공개하지 않았습니다.
