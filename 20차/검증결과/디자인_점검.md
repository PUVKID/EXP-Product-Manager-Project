# 20차 UI 점검 기록

확인일: 2026-10-26. Product Design audit/index/user-context/get-context/critical-overrides 및 Game Studio web-3d-asset-pipeline 지침을 읽고 기존 네이티브 앱에 적용했습니다. 부모가 완료한 Product Design 사전점검 결과는 저장 맥락 없음이며, 이번 요청의 흑백/나눔고딕 Bold/기존 앱 및 실제 제작 3D 자산을 기준으로 삼았습니다.

## 변경 전 관측

부모가 인계한 `before/Dark-schedule.png`를 직접 열어 확인했습니다. 상단과 본문에 예약 제목이 반복되고 시간대 기능이 꺼져 있어도 표가 공간을 차지합니다. 총 횟수 비활성 라벨은 어두운 바탕과 대비가 낮았습니다. 다섯 개 토글과 관련 입력이 동시에 노출되어 방식 구분이 어려웠습니다.

## 구현 대응

1. 공통 상단은 작업 공간으로 표시하고 예약 본문은 등록 흐름 설정으로 구분했습니다. 테마 세 가지와 라이선스 상태는 유지했습니다.
2. 한 번/1개씩/전체 목록 반복 선택을 하나로 모았습니다. 시간표와 횟수는 해당 기능 선택 때만 펼칩니다.
3. 전체 목록은 N분 간격/매시 지정분 선택 후 해당 숫자만 보여 줍니다. 입력 범위와 15:02 예시를 화면과 도움말에 표시합니다.
4. 실행 중 변경 잠금과 Studio/Pro 권한을 UI에서도 유지합니다. 실제 보안 권한은 기존 Controller에서 집행합니다.
5. 기존 제작물인 92삼각형 GLB와 구운 48프레임 PNG를 활용합니다. Dashboard의 브랜드 컨트롤은 진행률을 함께 표시하며 텍스트와 별도 영역을 사용합니다. 아이콘은 기존 제작 자산을 보존했습니다.
6. 등록방식과 테마 선택에 방향키/Home/End 및 포커스 표시를 제공합니다. 숫자의 긴 입력 복구, 5개 배율, 양 테마, 잠금/저장/복원, 모션 수명은 TESTBUILD 검사에 포함했습니다.

## 현재 증거 한계

이 기록 시점은 구현 소스 동결 후, 통합 빌드 및 변경 후 실제 화면 검증 전입니다. 변경 후 완료 판정이나 접근성 적합성 전체를 주장하지 않습니다. 운영 앱 실행·인증·상품 게시·관리자 초기화는 수행하지 않습니다. 관리자 및 초기화는 공통 시각 구성의 격리 렌더와 정적 검토 범위입니다.

## 변경 후 실제 검사

RepeatDesign 1,248개, Redesign 1,312개, DPI 다섯 배율에서 각 1,137개로 합계 8,245개 항목 통과(모든 프로세스 종료 코드 0). 실제 렌더 PNG에서 대시보드 양 테마, 예약, 자동 등록, 상품, 로그인, 라이선스, 설정, 도움말, 상품 편집을 직접 열어 확인했습니다. 입체 E와 진행 숫자는 별도 영역을 유지하고, 전체목록은 필요한 입력 하나만 표시하며, 기존 시간표와 배송 입력도 유지되었습니다. 전체 결과와 최종 소스 해시는 ui-final-evidence.json에 있습니다. 로그는 파일에 전체 저장되었고 도구 응답에서는 끝부분만 표시했습니다. 독립 검증은 부모가 별도 배정합니다.


## 수리 5 문구 검증

전체 목록 안내가 선택값을 표시하도록 두 파일만 수정한 뒤 부모 통합 빌드로 RepeatDesign만 재실행했습니다. 1,298개 통과/0실패, 종료 코드0이며 추가50개 요약 갱신 검사도 포함합니다. 새 Dark-1-batch-clock 및 Light-1-batch-interval 이미지를 직접 열어 매시00분/60분간격 문구와 예시, 첫회즉시, 지연회차 설명을 확인했습니다. 동결 후 두 파일 해시는 동일합니다. 최신 증거는 ui-repair05-evidence.json, 이미지는 repeat-repair05/에 있습니다. 이전 전체UI/DPI 결과는 재실행 없이 보존하며 적용검사합계는8,295개입니다. 독립 영수증은 발급하지 않았습니다.
