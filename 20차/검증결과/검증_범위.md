# EXP 20차 검증 범위

2026-10-26. 버전 2.4.0. Product Design의 화면 점검과 Game Studio의 3D 자산 제작 절차를 Windows 앱 구조에 적용했습니다. 실제 입체 E 모델, 48프레임 이미지, 다중 크기 ICO를 만들었습니다. 외부 렌더링 서버 없이 앱 안에서 표시합니다.

## 확인한 항목

- 전체 목록 첫 회차 즉시 등록, 시작 기준 N분 간격, 매시 지정분, 느린 회차의 지난 슬롯 건너뛰기.
- 전체 목록에 기존 등록 상품 포함, 0/31/65개 목록, 중복 시작 방지, 중지·일시정지, 인증·일일한도·실패 처리.
- 반복 검사 110개 통과. 완료 콜백 지연 제어 검사 5개 통과. 이전 간헐 실패 원문은 work 및 evidence에 보존했습니다.
- UI 변경별 적용 검사 합계 8,295개: 최신 반복 UI 1,298개, 일반 UI 1,312개, 배율 5종 각 1,137개. 동일 최종 실행 한 번의 합계는 아닙니다.
- 배율 100/125/150/175/200%는 테스트용 배율을 적용한 폼 렌더입니다. 다른 물리 모니터에서 직접 실행한 검사는 아닙니다.
- 원본 보안·기존 로직 24개 파일 해시 일치, 소스 102개 UTF-8 확인.
- 사용자·관리자·초기화 프로그램과 설치 파일 빌드 성공. 고객 ZIP에는 관리자 발급·초기화 도구를 넣지 않았습니다.

## 전달과 한계

독립 검증의 최종 판정과 실제 실행 결과는 evidence 및 .codex/routing-state의 영수증에 기록합니다. 본 문서는 구현자 검사 범위 설명입니다. 실제 상품 게시, 사용자 인증, 운영 프로그램 종료·설치·초기화는 수행하지 않았습니다. 운영 환경의 모든 오류가 없다고 보장하지 않습니다.

상품과 인증 자료는 그대로 두었습니다. 설치 후 새 버전 2.4.0을 확인하세요. 전체 목록 반복은 예약에서 선택하고 자동 등록 화면에서 시작합니다. Studio·Pro 권한과 기존 한도가 적용됩니다.
