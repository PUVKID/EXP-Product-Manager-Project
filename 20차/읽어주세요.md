# EXP 20차 · 2.4.0

상품 목록 전체를 반복 등록하는 기능과 흑백 입체 디자인을 적용한 버전입니다.

## 전체 상품을 매시간 등록하기

1. 상품 관리에서 제목·가격·사진 등 상품 정보를 준비합니다.
2. 예약에서 ‘전체 목록 반복’을 선택합니다.
3. 반복 시각을 선택합니다.
   - N분 간격: 60분을 입력하면 15:02에 시작한 다음 회차는 16:02입니다.
   - 매시 지정분: 00분을 입력하면 15:02에 시작한 다음 회차는 16:00입니다. 20분이면 15:20입니다.
4. 자동 등록에서 시작합니다. 첫 회차는 바로 진행합니다.

전체 목록 반복은 이미 등록된 상품도 포함합니다. Studio·Pro에서 사용할 수 있고 기존 하루 등록 한도가 적용됩니다. 목록이 한도를 넘으면 모든 상품을 올리기 전에 중단될 수 있습니다.

앱과 PC가 켜져 있어야 반복됩니다. 회차가 오래 걸려 예정 시간을 넘기면 다음 미래 시각을 기다리며 지난 회차를 몰아서 실행하지 않습니다. 중지하거나 한도·인증 문제로 중단되면 자동으로 다시 시작하지 않습니다. 개별 상품이 실패하면 해당 회차의 나머지 상품을 처리한 뒤 실패 건수를 안내하고 반복을 멈춥니다.

## 설치와 파일

- 고객 배포/EXP_Setup_2.4.0.exe: 설치·업데이트용
- 고객 배포/EXP.exe: 사용자 프로그램
- 관리자 전용/EXP-Master.exe: 관리자 발급 도구
- 관리자 전용/EXP-Reset.exe: 초기화 관리 도구
- EXP_2.4.0_고객배포.zip: 고객용 파일만 포함한 압축 파일
