# 반복과 시간대 예약

## 등록 방식 선택
예약의 등록 방식에서 **한 번**, **1개씩**, **전체 목록 반복** 중 하나를 고르세요. 선택한 방식에 필요한 입력만 표시됩니다. 시작한 뒤에는 예약 설정을 바꿀 수 없습니다. 중지 후 변경하세요.

## 전체 목록 반복
Studio / Pro에서 사용할 수 있습니다. 유효한 전체 상품 목록을 즉시 등록한 뒤 반복합니다. 이미 등록된 상품도 포함하며, 한 회차의 전체 목록은 순서대로 처리합니다.

- **N분 간격**: 1~1440분. 15:02에 시작하고 60분으로 설정하면 다음 시각은 16:02입니다.
- **매시 지정분**: 0~59분. 15:02에 시작하고 0분을 선택하면 다음 시각은 16:00, 20분을 선택하면 15:20입니다.

오래 걸린 회차 뒤에는 다음 미래 시각을 기다리며, 지나간 회차를 몰아 실행하지 않습니다. 자동 등록 화면에서 현재 방식과 다음 실행 시각을 확인할 수 있습니다. 대기 중에도 일시정지·계속·중지를 사용할 수 있습니다.

로그인 실패, 예외, 시도한 상품이 없는 회차는 중단합니다. 개별 상품 실패가 있으면 나머지 상품까지 처리한 뒤 안내하고 반복을 중단합니다. 기존 인증과 일일 등록 한도가 적용됩니다.

## 1개씩 등록
상품 사이의 기본 간격을 분 단위로 입력하세요. 시간대별 간격을 켜면 시간표가 펼쳐집니다. 시간대는 한국 시각 기준이며, 겹치면 나중에 시작한 시간대가 우선합니다. 목록 완료 후 반복을 켜면 처음 1회를 포함한 총 횟수를 지정할 수 있습니다. 시간대·반복·이미 등록된 상품 포함은 Studio / Pro에서 사용할 수 있습니다.

## 다음 예약 시작
번개장터 서버 시각이 확인되어야 시작할 수 있습니다. 실행 중 설정은 시작할 때의 값으로 유지됩니다.

시간대 입력은 09:00 형식이며 자정을 넘는 시간대도 사용할 수 있습니다. 예를 들어 08:50 등록 후 간격이 45분이어도 새 시간대가 09:00에 시작하면 09:00부터 다음 상품을 처리하며 이전 대기시간을 이어 가지 않습니다.
