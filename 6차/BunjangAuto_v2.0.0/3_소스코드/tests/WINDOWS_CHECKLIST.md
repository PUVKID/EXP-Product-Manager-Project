# Windows 에서 직접 확인해야 하는 항목 (제작 환경이 Linux 라서 자동 검증하지 못한 부분)

`tests/regression.sh` 로 자동 확인된 것: 빌드, SelfTest 98항목, 서버·종단 전송, 비밀정보 제거, 구버전 데이터 마이그레이션, 관리자 대시보드(jsdom) 렌더링.
아래는 **Windows 10/11 PC 에서 한 번씩** 확인해 주세요. 이상이 있으면 `%AppData%\BunjangAuto\logs` 의 로그와 화면 캡처를 보내 주시면 됩니다.

| # | 확인 항목 | 방법 | 결과 |
|---|---|---|---|
| 1 | 실행 / 단일 실행 | exe 를 두 번 실행 → 두 번째는 "이미 실행 중" | ☐ |
| 2 | 이용약관(제7조 신설) 재동의 | 첫 실행 때 약관 창이 다시 나오고 동의 | ☐ |
| 3 | 라이선스 / PC 고유번호 / 키 인증 | 기존 키로 통과, 라이선스 화면에서 복사·재인증 | ☐ |
| 4 | Guard | dnSpy 등 분석 도구 실행 중 → 종료 안내 | ☐ |
| 5 | 기존 데이터 | v1 의 `%AppData%\BunjangAuto` 가 있는 PC 에서 실행 → 상품/설정이 그대로 | ☐ |
| 6 | CSV 불러오기/저장/양식 | 기존 CSV 열기, 저장 후 엑셀에서 열기 | ☐ |
| 7 | Chrome 실행 / 프로필 / ChromeDriver / 로그인 | 로그인 테스트 | ☐ |
| 8 | 상품 1개 실제 등록 (이미지·카테고리 포함) | 자동 등록 → 시작 | ☐ |
| 9 | 1개씩 / 반복 / 시간대별 / 중복 허용 | 예약 화면 설정 후 시작 | ☐ |
| 10 | **일시정지 / 계속 / 중지** (신규 기능) | 등록 도중 일시정지 → 계속, 일시정지 중 중지 | ☐ |
| 11 | 테마 Light / Dark / System | 헤더 버튼, 설정 화면, 재실행 후 유지, Windows 앱 모드 변경에 System 이 따라가는지 | ☐ |
| 12 | 제목 표시줄 색(Windows 11) | 다크에서 제목 표시줄이 어둡게 / 둥근 모서리 | ☐ |
| 13 | DPI 100/125/150/175/200% | 사이드바·Dashboard 카드·표·대화상자·도움말이 잘리지 않는지 | ☐ |
| 14 | 사이드바 아이콘 | Segoe Fluent Icons(Win11) / Segoe MDL2 Assets(Win10) 로 표시 | ☐ |
| 15 | 도움말 검색 | 사용 설명서에서 "CSV" 검색 → 목록 필터와 본문 강조 | ☐ |
| 16 | 중앙 로그 | 서버 주소를 넣고 실행 → 관리자 웹 대시보드의 Users/Live Logs 에 나타남 | ☐ |
| 17 | 관리자 센터(EXE 내부) | 설정 → 관리자 로그인 → 사이드바에 관리자 센터 | ☐ |
| 18 | 네트워크 차단 | 서버 주소를 틀리게 넣어도 자동등록이 정상 동작 | ☐ |
