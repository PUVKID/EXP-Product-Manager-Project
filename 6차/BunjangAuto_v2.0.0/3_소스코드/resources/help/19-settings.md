# 설정

**설정** 화면에서 바꿀 수 있는 것

- **테마**: 라이트 / 다크 / 시스템
- **Chrome 경로**: 크롬을 자동으로 못 찾을 때 `chrome.exe` 위치를 직접 지정
- **데이터 폴더 열기**: `%AppData%\BunjangAuto` 를 엽니다
- **운영 로그 전송 상태**: 중앙 서버로 운영 로그가 전송되는지 확인

## 데이터 폴더의 파일
| 파일 | 내용 |
|---|---|
| settings.json | 설정 (이 PC 전용으로 암호화) |
| products.json | 상품 목록 (이 PC 전용으로 암호화) |
| selectors.json | 번개장터 화면 요소 주소. 사이트가 바뀌면 이 파일만 고쳐도 됩니다 |
| logs | 날짜별 로그 |
| screenshots | 등록 실패 때 저장한 화면 |

## 운영 로그 전송
프로그램은 문제 해결과 사용 현황 파악을 위해 **운영 로그, 오류 정보, 시스템 정보(프로그램 버전, 윈도우 버전, CPU, 메모리, 그래픽, 화면 해상도), 기능 사용 횟수**를 관리자 서버로 보냅니다. 이용약관 제7조에 명시되어 있습니다.

다음은 **절대 전송하지 않습니다**: 비밀번호, 쿠키, 세션 토큰, 인증 정보, 개인키, 카드·계좌 정보. 로그에 우연히 섞여 있을 수 있는 값은 보내기 전에 자동으로 지웁니다.

인터넷이 없어도 프로그램은 정상 동작합니다. 못 보낸 기록은 모아 두었다가 연결되면 보냅니다.
