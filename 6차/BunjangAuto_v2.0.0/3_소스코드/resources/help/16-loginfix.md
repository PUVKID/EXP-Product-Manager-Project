# 로그인 문제 해결

- **로그인 확인이 안 됨**: 열린 크롬 창에서 번개장터 로그인이 실제로 되어 있는지 확인합니다. 화면 오른쪽 위에 알림 아이콘이 보이면 로그인된 상태입니다.
- **180초 안에 로그인을 못 했음**: 다시 **로그인 테스트**를 눌러 처음부터 하세요.
- **자꾸 로그인이 풀림**: **로그인 상태 초기화**를 누른 뒤 다시 로그인합니다. 크롬 창을 직접 닫지 말고 프로그램이 닫게 두세요.
- **다른 계정으로 바꾸고 싶음**: 크롬 창에서 로그아웃 후 다른 계정으로 로그인하고, 프로그램에서 **로그인 상태 초기화**를 누릅니다.

> 프로그램은 아이디·비밀번호·쿠키를 읽거나 저장하지 않습니다.
