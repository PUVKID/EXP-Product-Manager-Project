# CSV 사용법

상품이 많으면 엑셀에서 표로 만들어 한 번에 불러오는 것이 편합니다.

## 순서
1. **CSV 양식 만들기**로 예시가 들어 있는 양식 파일을 저장합니다.
2. 엑셀에서 열어 상품을 한 줄에 하나씩 채웁니다.
3. 저장할 때는 **CSV UTF-8(쉼표로 분리)** 을 권장합니다.
4. **CSV 불러오기**로 파일을 고릅니다. 이미 목록이 있으면 "지우고 새로 불러올지, 아래에 이어 붙일지" 물어봅니다.
5. **CSV 저장**으로 현재 목록을 파일로 내보낼 수 있습니다. 백업용으로 자주 저장해 두세요.

## 읽을 수 있는 파일
- 글자 모양: UTF-8(BOM 있음/없음), UTF-16, UTF-32, 한국어 윈도우 엑셀 기본 CSV(CP949)
- 구분 글자: 쉼표, 탭, 세미콜론
- 큰따옴표로 감싼 칸 안의 쉼표와 줄바꿈
- 머리글 이름이 조금 달라도 같은 열로 인식합니다. 예) 상품명 → 제목, 판매가 → 가격

> 엑셀에서 'CSV(쉼표로 분리)'로 저장하면 이모지가 `?`로 바뀌어 복구되지 않습니다. 불러올 때 제목·설명에 `??`가 보이면 원본에서 'CSV UTF-8'로 다시 저장하세요.
