# 라이선스 문제 해결

## TPM 사용 불가
Windows 보안의 보안 프로세서 또는 tpm.msc에서 TPM 상태를 확인하세요. TPM 및 P-256 지원이 필요하며 소프트웨어 키로 자동 대체하지 않습니다.

## 기기 변경 또는 TPM 초기화
원래 등록한 Windows 계정인지 확인하세요. TPM 초기화·메인보드 교체·Windows 재설치로 키를 잃었다면 새 등록 요청을 관리자에게 전달해 재발급받으세요. 라이선스 파일만 복사해도 키가 복구되지는 않습니다.

## 날짜 및 파일 오류
Windows 날짜·시간을 바로잡고 관리자에게 원본 라이선스 파일을 다시 요청하세요. 서명/기기 검증 실패 시 실행할 수 없습니다.

## 오프라인 제한
원격 즉시 폐기, 동시 사용 탐지, 시각 조작과 VM 복제를 완전히 막는 기능은 제공하지 않습니다.
