# EXP 18차 · 2.3.0

오프화이트·잉크 네이비·코랄 포인트와 나눔고딕 Bold를 적용한 디자인 수정본입니다.

## 파일 선택

- `고객 배포/EXP_Setup_2.3.0.exe`: 고객에게 전달할 통합 설치 프로그램입니다. 기존 방식대로 인증키의 등급에 맞춰 설치됩니다.
- `고객 배포/EXP.exe`: 설치 전 직접 확인할 수 있는 사용자 실행 파일입니다. 인증과 사용량 제한은 설치본과 동일합니다.
- `관리자 전용/EXP-Master.exe`: 윤석님용 키 발급 프로그램입니다. 고객에게 전달하지 마세요.
- `관리자 전용/EXP-Reset.exe`: 인증 정보를 초기화하는 관리 도구입니다. 초기화가 필요할 때만 사용하세요.
- `소스코드`: 이번 버전의 재빌드용 코드와 내장 글꼴·라이선스입니다.
- `디자인`: 선택한 색상의 디자인 시안입니다. 시안의 상품·숫자는 예시입니다.

## 변경 내용

- 한눈에 보기를 가로 통계 4개, 자동 등록 상태, 계정·라이선스 상태, 긴 최근 활동 영역으로 재구성했습니다.
- 입력칸·선택칸·버튼·카드·진행 표시·관리 도구의 공통 색상과 여백을 맞췄습니다.
- 라이트·다크·시스템 테마를 유지하고 짧은 선택·호버·진행 전환을 적용했습니다.
- 사용자 앱, EXP Master, 초기화 도구와 설치 파일의 아이콘을 코랄 색상으로 통일했습니다.

## 사용 시 참고

상품 목록, 인증키, 등급별 한도, 예약, 발급 키는 이번 디자인 수정에서 바꾸지 않았습니다. 기존 앱을 사용 중이면 작업을 마친 뒤 직접 종료하고 새 파일을 실행하거나 설치하세요. 이 작업에서는 설치된 프로그램을 교체하거나 사용자 인증을 대신하지 않았습니다.

기존 등록 성공 판정·실패 집계 문제는 이번 디자인 수정의 해결 범위에 포함되지 않습니다. UI 검사 통과가 실제 상품 게시나 모든 PC에서의 무오류를 보장하지는 않습니다.
