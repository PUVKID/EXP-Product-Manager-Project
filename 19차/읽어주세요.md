# EXP 19차 · 2.3.1 · 첫 번째 흑백 디자인

처음 제시한 검정·흰색 시안을 적용했습니다. 라이트 모드는 흰색 바탕과 검정 버튼, 다크 모드는 차콜 바탕과 흰색 버튼입니다. 네이비·코랄 장식색을 제거하고 큰 등록 진행 영역, 원형 진행, 하단 3개 통계와 최근 활동을 배치했습니다. 글꼴은 나눔고딕 Bold입니다.

## 실행 및 설치

- `고객 배포/EXP_Setup_2.3.1.exe`: 기존 설치본을 업데이트하거나 처음 설치할 때 사용합니다.
- `고객 배포/EXP.exe`: 설치 전 직접 실행할 사용자 프로그램입니다.
- `관리자 전용/EXP-Master.exe`: 키 발급 도구입니다. 고객에게 전달하지 마세요.
- `관리자 전용/EXP-Reset.exe`: 초기화가 필요할 때만 사용하는 관리 도구입니다.

자동 등록 중이면 작업을 마친 뒤 EXP를 완전히 종료하고 설치 파일을 실행하세요. 창을 닫아 트레이에 남아 있다면 앱의 종료 메뉴를 사용하세요. 새 파일이 만들어져도 이미 실행 중인 이전 버전의 화면은 자동 교체되지 않습니다. 새 화면의 버전 표시는 2.3.1입니다.

기존 인증키와 상품 정보는 유지했습니다. 이 작업에서 인증이나 설치를 대신 수행하지 않았습니다. 원형 숫자는 현재 등록 작업의 완료/전체 진행이며, 오늘의 사용량으로 표시하지 않습니다. 상품 목록의 등록 성공/실패 수와 일일 한도는 별개의 값입니다.

## 기능 보존과 검사 범위

사진 12장, 카테고리 3단계, 일반·반값택배, 배송 요금, 사진 순서, 저장·취소, 라이선스와 예약 기능을 유지합니다. 시안에 생략된 실제 입력 항목을 제거하지 않았습니다.

화면 검사는 운영 상품·인증을 사용하지 않는 격리 테스트로 수행합니다. 관리자/초기화의 실제 발급·초기화 동작 및 실제 상품 게시·다른 PC 설치는 이번 디자인 검사의 범위가 아닙니다. 기존 등록 성공 판정·실패 집계 문제는 이 디자인 변경으로 수정됐다고 주장하지 않습니다.
