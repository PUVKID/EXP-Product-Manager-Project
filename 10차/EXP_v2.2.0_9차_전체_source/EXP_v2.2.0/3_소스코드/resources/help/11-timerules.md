# 시간대별 등록

시간대마다 다른 간격으로 등록할 수 있습니다. 예를 들어 새벽에는 40분, 낮에는 60분 간격으로 올립니다.

## 설정
1. **예약** 화면에서 **1개씩 등록**을 켭니다.
2. **시간대별로 간격 지정**을 켭니다. 기본 간격 대신 표가 사용됩니다.
3. **시간대 추가**로 줄을 만들고 시작, 종료, 간격(분)을 적습니다.

## 작성 규칙
- 시각은 `HH:mm` 형태입니다. (예: 09:00) 하루의 끝은 `24:00` 입니다.
- 자정을 넘기는 시간대는 `22:00` ~ `06:00` 처럼 적습니다.
- 시작과 종료가 같으면 24시간 내내로 봅니다.
- 간격은 1~1440분입니다.

## 동작 방식
시간대 **밖**에서는 등록하지 않고, 다음 시간대가 시작될 때까지 기다렸다가 자동으로 시작합니다. 시작할 때 시간대가 잘못되어 있으면 어디가 문제인지 안내합니다.
