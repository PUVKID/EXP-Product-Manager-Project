# 상품 추가

## 직접 입력하기
1. **상품 관리**에서 **상품 추가**를 누릅니다.
2. 제목과 가격은 꼭 입력해야 합니다.
3. 카테고리는 대분류 → 중분류 → 소분류 순서로 고릅니다.
4. 상품 상태, 수량, 태그, 설명, 배송비 포함 여부, 사진을 채웁니다.
5. **확인**을 누르면 목록에 추가됩니다.

## 고치기 / 지우기
- 행을 선택하고 **편집**을 누르면 같은 입력 창이 열립니다. 행 머리글을 더블클릭해도 열립니다.
- **삭제**는 선택한 행을 지웁니다. 여러 줄을 선택해 한 번에 지울 수 있습니다.
- **상태 초기화**는 선택한 행의 상태메시지·상품번호·마지막 등록 시각을 비워 다시 등록 대상으로 만듭니다.

표의 칸을 직접 클릭해 고쳐도 됩니다. 상태메시지, 상품번호, 마지막 등록은 프로그램이 채우는 칸이라 고칠 수 없습니다.
