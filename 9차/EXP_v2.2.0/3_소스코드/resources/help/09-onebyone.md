# 1개씩 등록

**예약** 화면에서 **1개씩 등록**을 켜면, 정해진 간격으로 상품을 한 개씩 올립니다. 모두 올리면 자동으로 끝납니다.

## 설정
- **기본 간격**: 몇 분마다 1개씩 올릴지 (1~1440분)
- 기본값은 20분입니다.

## 동작 방식
1. 첫 상품을 바로 올립니다.
2. 다음 등록 시각까지 기다립니다. **자동 등록** 화면에 남은 시간이 표시됩니다.
3. 등록할 상품이 없으면 "모두 등록해 종료합니다"를 로그에 남기고 끝납니다.

등록에 실패한 상품은 같은 회차 안에서는 다시 시도하지 않습니다. 원인을 고친 뒤 **상태 초기화**를 하고 다시 시작하세요.
