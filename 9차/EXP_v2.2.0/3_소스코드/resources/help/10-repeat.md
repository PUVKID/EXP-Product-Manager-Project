# 반복 등록

목록을 다 올린 뒤 **처음 상품부터 다시** 올리고 싶을 때 씁니다. (1개씩 등록을 켠 상태에서만 사용할 수 있습니다.)

## 설정
- **목록을 다 올리면 처음 상품부터 다시 올리기**를 켭니다.
- **총 N회**를 정합니다. 목록 전체를 한 번 올리는 것이 1회입니다. 처음 1회가 포함된 횟수입니다.

## 동작 방식
- 2회차부터는 이미 등록된 상품도 목록 순서대로 다시 등록합니다.
- 화면에 현재 회차가 `1/3회차`처럼 표시되고, 로그에도 남습니다.
- 정해진 횟수를 모두 마치면 자동으로 끝납니다.
