# 로그인

프로그램은 번개장터 **아이디와 비밀번호를 묻지 않습니다.** 대신 전용 크롬 창을 열어 주고, 그 창에서 사용자가 직접 로그인합니다.

## 로그인하는 방법
1. 왼쪽 메뉴 **로그인** 에서 **로그인 테스트**를 누르거나, **자동 등록**에서 **시작**을 누릅니다.
2. 크롬 창이 열리고 번개장터 로그인 화면으로 이동합니다.
3. 그 창에서 직접 로그인합니다. 문자 인증, 소셜 로그인도 모두 가능합니다.
4. 로그인이 끝나면 프로그램 안내창에서 **예**를 누릅니다.

로그인 정보는 이 프로그램 전용 크롬 프로필에 남기 때문에, 다음부터는 자동으로 이어집니다.

## 로그인이 풀린 것 같을 때
**로그인 상태 초기화**를 누른 뒤 다시 로그인합니다.
