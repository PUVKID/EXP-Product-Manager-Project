# v2.1.0

- RSA/MachineGuid 기반 인증을 Ed25519 서명 + TPM P-256 소유 증명으로 교체.
- 기존 PC ID 계산은 데이터 암호화/진단 호환성에 한해 유지.
- 등록 요청 내보내기·서명된 라이선스 파일 가져오기를 기존 인증 창과 라이선스 페이지에 추가.
- 관리자 발급 도구를 분리하고 DPAPI·ACL 키 보호, 암호화 백업/복원, 발급 기록 조회/JSON 내보내기 추가.
- 중복 JSON·필드 타입·제품·버전·권한·만료·키 불일치 검사 및 실패 시 거부.
- DPAPI 인증 시각 기록, 손상/쓰기 실패 거부, 상품별 재검증 추가.
- 한국어 Windows의 `나눔고딕` 글꼴 이름도 기존 내장 Nanum Gothic으로 인식하도록 수정. 색상/배치/아이콘/폰트 파일은 기존 그대로.
- 기존 봇, 선택자, CSV, 설정/상품 보관, 예약, 로그인, 중앙 로그 코드를 유지.
- Windows 재현 빌드/테스트/고객 ZIP 생성/선택적 Authenticode/Inno Setup 구성 추가.
- 이전 개인키, 구형 관리자 바이너리, 키 생성 잔여 파일을 새 전달본에서 제외.
- 사용자 요청대로 설치형 결과물 생성은 다음 단계로 미룸.
