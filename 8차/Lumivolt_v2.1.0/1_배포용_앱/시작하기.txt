Lumivolt v2.1.0 실행형

압축을 풀고 Lumivolt.exe를 실행하세요. 설치 프로그램이 아닙니다.
Windows 10/11, .NET Framework 4.7.2 이상, 사용 가능한 TPM/P-256, Chrome이 필요합니다.

1. '등록 요청 저장'으로 .lvrequest 파일을 만듭니다.
2. 관리자에게 파일을 전달합니다.
3. 받은 .lvlicense를 '라이선스 파일 열기'로 읽고 '인증'을 누릅니다.

기존 v2.0 라이선스는 새 방식으로 재발급해야 합니다.
설정/상품 데이터의 저장 위치와 형식은 그대로입니다.
기존 데이터를 삭제하거나 TPM을 초기화하지 마세요.
