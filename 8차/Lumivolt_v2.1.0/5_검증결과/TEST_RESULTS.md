## UI 및 보존 범위

원본 소스도 별도 임시 사용자 데이터 경로로 빌드하여 같은 Windows에서 20개 화면을 렌더링했습니다. `screenshots-before`와 `screenshots-after`로 비교할 수 있습니다. 라이선스 화면의 파일 버튼과 안내 문구가 추가되었고, 한국어 Windows 글꼴 이름 인식 오류 수정으로 원래 포함된 나눔고딕 Bold가 정상 적용됩니다. 원본 스크린샷과 완전히 동일한 픽셀을 주장하지 않습니다.

`Bot.cs`, `Storage.cs`, `Vault.cs`, `Schedule.cs`, `Selectors.cs`, `DriverManager.cs`, `MainForm.cs` 및 라이선스 이외 페이지의 주요 소스와 기존 리소스를 해시 비교했습니다. 기존 상품 등록 로직 자체는 변경하지 않았습니다. 상세 변경 목록은 `SOURCE_COMPARISON.json`을 참고하세요. `Runner.cs`에는 상품마다 인증을 재검사하는 호출만 추가했습니다.

초기 검증에서 Platform KSP가 알고리즘 이름을 `ECDSA_P256` 대신 `ECDSA`로 반환한 차이, 한국어 글꼴 이름 비교 오류를 발견했습니다. 전자는 공급자·알고리즘 그룹·P-256 공개키 blob 검사로 수정하고, 후자는 동일 글꼴의 한국어 이름을 허용한 뒤 재검증했습니다.

## 미실행/추가 확인 항목

- 실제 번개장터 로그인과 상품 게시, 반복 등록의 장시간 운영. 실제 고객 계정에 상품을 게시하지 않았습니다.
- 다른 물리 PC에 파일을 복사하는 테스트. 다른 공개키를 가진 라이선스가 거부되는 통합 테스트는 통과했습니다.
- 재부팅, TPM 초기화, 메인보드 교체, Windows 사용자 변경, 권한 차단 상태의 실제 하드웨어 시험.
- 신뢰할 수 있는 원격 TPM attestation, 고급 VM/vTPM 복제 대응, 원격 폐기 기능. 구현 범위에 포함되지 않습니다.
- 새 Windows에서 설치·제거·바로가기·업그레이드. 요청대로 설치형은 미루었으므로 Inno Setup 설정만 제공하며 설치 파일을 생성/실행하지 않았습니다.
- Windows Authenticode 서명: 인증서 미제공으로 미서명.
- Visual Studio / dotnet SDK 빌드 경로: SDK 미설치. Windows 내장 csc 빌드는 실행했습니다.

원본 라이브러리에서 발생하던 .NET 후방 호환 어셈블리 경고가 남아 있습니다(CS1685 및 원본 Selenium 참조 버전 관련 경고). 실제 포함된 DLL 로딩과 110개 회귀 테스트는 통과했으나 신규 OS/Chrome 버전별 실제 브라우저 등록 시험을 대신하지는 않습니다.
