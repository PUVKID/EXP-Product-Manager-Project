# 상품 데이터 작성법

| 열 | 설명 | 예시 |
|---|---|---|
| 제목 | 필수. 상품 이름 | 아이폰 15 프로 256GB |
| 가격 | 필수. 숫자만. 원, 쉼표, ₩ 는 자동 제거 | 1050000 |
| 카테고리 | 대분류>중분류>소분류 | 디지털>휴대폰>애플 |
| 상태 | 화면에 보이는 글자 그대로 | 사용감 적음 |
| 수량 | 비우면 1 | 1 |
| 태그 | 쉼표로 구분 | 아이폰,애플 |
| 이미지 | 사진 경로, 세미콜론(;)으로 구분 | photos\a.jpg;photos\b.png |
| 설명 | 줄바꿈 가능 | 풀박스입니다. |
| 배송비포함 | Y / N | Y |

## 상품 상태로 쓸 수 있는 값
새 상품(미사용), 사용감 없음, 사용감 적음, 사용감 많음, 고장/파손 상품

## 카테고리 작성 요령
번개장터 화면에 보이는 이름과 **똑같이** 적어야 합니다. 철자가 다르면 등록이 실패합니다. 확실하지 않으면 **상품 추가** 창의 카테고리 목록에서 골라 보세요.

## 배송비포함 값
Y, O, TRUE, 1, 예, 포함 중 하나면 "포함"으로 읽고, 나머지는 "별도"로 읽습니다.
