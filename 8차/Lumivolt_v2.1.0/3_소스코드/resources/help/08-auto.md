# 자동 등록

**자동 등록** 화면에서 시작합니다.

## 버튼
- **시작** — 설정대로 등록을 시작합니다.
- **일시정지** — 지금 하던 단계가 끝나는 대로 멈춥니다. **계속**을 누르면 이어서 진행합니다.
- **중지** — 가능한 한 빨리 멈추고 자동 진행도 끝냅니다. 일시정지 중에도 바로 중지됩니다.

## 화면에 보이는 것
현재 상품, 진행률, 이번 실행의 성공/실패 개수, 남은 상품 수, 현재 작업 상태, 다음 실행 시각

## 등록 대상
- 기본: 유효한(제목·가격이 있는) 상품 중 아직 등록되지 않은 것
- **중복 등록 허용**을 켜면 이미 등록된 상품도 목록 순서대로 다시 등록합니다.
- **1개씩 등록**을 끄면 한 번에 최대 30개까지 연달아 등록합니다.

각 상품 사이에는 3~8초의 쉬는 시간이 무작위로 들어갑니다.
