# 라이선스 등록

1. 인증 창에서 **등록 요청 저장**을 누릅니다. Windows TPM에 비이동형 P-256 키를 만들고 공개키 등록 요청(.lvrequest)을 저장합니다.
2. 등록 요청 파일을 관리자에게 전달하세요. PC 번호만으로는 발급되지 않습니다.
3. 관리자가 발급한 .lvlicense 파일을 **라이선스 파일 열기**로 선택하고 **인증**을 누릅니다. 키 문자열을 붙여 넣어도 됩니다.
4. 라이선스는 이 기기의 TPM 키와 등록한 Windows 계정에 연결됩니다.

## 연장
라이선스 화면에서 새 파일을 열거나 붙여 넣고 인증하세요. 기존 상품과 설정은 유지됩니다.

## 기존 버전
v2.0 RSA 라이선스는 새 방식으로 재발급해야 합니다. 구형 라이선스로 인증을 우회하지 않습니다.
